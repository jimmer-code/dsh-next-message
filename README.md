# 下一条消息

DeepSeek Harness 插件：根据对话预测下一条用户消息，在输入框里显示灰色建议，按 `Tab` 填入草稿。不会自动发送。

## 安装

1. 打开 DSH 的「插件 → 添加插件」。
2. 填 `github:jimmer-code/dsh-next-message`，点安装。
3. 确认 `dsh-next-message` 插件包是启用的。
4. 刷新页面；如果「插件 → dsh-next-message」的设置页没出现，重启一次 DSH。

## 使用

1. 正常发消息，等助手回复完。
2. 输入框空着时，会出现一条灰色建议。
3. 想用：按 `Tab` 填入草稿。
4. 不想用：直接打字，建议会自动消失；按 `Esc` 本回合不再显示。
5. 删掉 `Tab` 填入的内容后，建议会重新出现，不会再请求模型。

## 手机

手机端默认开启预测，显示在输入框下方：

1. 点「填入」把建议放进草稿。
2. 点「×」关闭本回合的建议。
3. 输入栏右侧的「预测」按钮可以随时开关手机端预测，只影响当前设备。

桌面端的「显示位置」设置不影响手机端；手机端固定用下方建议栏。

## 设置

打开「插件 → dsh-next-message」：

| 控件 | 作用 |
|---|---|
| 启用预测 | 打开或关闭 |
| 预测模型 | 默认跟随当前会话；也可以固定一个模型 |
| 桌面显示位置 | 输入框内，或输入框下方（手机端固定用下方） |

## 其他安装方式

命令行 / 网页版：

```sh
dsh plugin --profile <profile> add github:jimmer-code/dsh-next-message
```

桌面版的 profile 由应用管理，只能用上面的插件页。

本地开发：

```sh
git clone https://github.com/jimmer-code/dsh-next-message.git
cd dsh-next-message
npm install
```

然后在「插件 → 添加插件」里选这个目录。

## 说明

预测会把最近几条对话文本发给当前会话使用的模型服务。插件不写会话日志，也不会自动发送。

## 兼容性

在 DeepSeek Harness `0.2.2-rc.3` 上测试通过。输入框内位置如果错位，把「显示位置」切到「下方」。
